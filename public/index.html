M5Stack internal

把地址交给 Codex，Skill 自助流转。

人可以直接浏览，Codex 也能从同一个页面发现资源目录、读取接口说明，并在局域网内完成 Skill 上传和下载。

Codex 自助入口 查看资源 JSON
平台要点
  1. 一个入口网页与 Agent 共用同一服务地址。
  2. 接口自描述HTML、llms.txt 与 OpenAPI 同步暴露能力。
  3. 上传下载闭环Codex 可直接处理标准 Skill zip。

安装方法

下载后，把整个 Skill 文件夹放到 Codex skills 目录。

这是最容易出错的一步，所以固定在首页：下载 zip 后先解压，保留 skill-name\SKILL.md 这一层目录结构。

  1. 下载 zip在 Skill 详情窗口点击下载压缩包。
  2. 先解压不要只复制里面的单个 SKILL.md。
  3. 整包放入复制整个 skill-name 文件夹到 skills 目录。
正确结构 C:\Users\你的用户名\.codex\skills\skill-name\SKILL.md

Codex self-service

只给这个内部地址，Codex 就能自行发现接口。

根页面同时提供机器可读入口。Codex 应先读取 llms.txt， 再按实时目录完成检索、下载或上传，无需预装其他 Skill。

可直接告诉 Codex 当前服务：正在识别... 
访问这个地址的 /llms.txt，读取共享 Skill 列表和接口说明。按我的需求自行下载或上传 Skill；删除前必须先征得我确认。
01

发现与下载

  1. GET /api/skills 获取实时资源列表与每个 Skill 的链接。
  2. GET /api/skills/{id} 读取 SKILL.md、评论和更新记录。
  3. GET /api/skills/{id}/download 下载可直接安装的 zip。
02

打包与上传

  1. 压缩一个 Skill 文件夹，确认根目录中存在 SKILL.md。
  2. 把 zip 作为 archive 字段提交到 POST /api/skills/upload。
  3. 收到 201 后重新读取目录，确认共享版本已创建或更新。
Codex / PowerShell 上传命令 压缩包只能包含一个 Skill；同名上传会备份旧版本后更新。 
curl.exe -X POST "<BASE_URL>/api/skills/upload" -F "archive=@C:\path\skill.zip"
可直接爬取的接口
方法路径用途
GET/api/skills实时 Skill 目录
GET/api/skills/{id}详情、说明与历史
GET/api/skills/{id}/download可安装 zip
POST/api/skills/upload上传单个 Skill zip
GET/api/openapi.json完整接口结构

该服务没有登录鉴权，仅应部署在可信局域网。删除接口属于破坏性操作，Codex 必须获得用户明确确认后才能调用。
